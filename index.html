RESEARCH PROJECT

Japanese Mahjong Ready-Hand Prediction

以日本麻將（Riichi Mahjong）為研究情境，利用牌局中可公開觀察的資訊， 預測對手是否已進入聽牌（ready-hand）狀態。

Task Binary Classification
Models CNN · ResNet · Transformer
Input Current State · Action History
Goal Opponent Ready-Hand Prediction

本專題將對手聽牌預測建模為監督式二元分類問題，僅採用牌局中的公開資訊作為輸入， 並比較靜態牌局表示（Current Representation）與保留行動時序的歷史表示（History Representation）。 在一致的實驗架構下評估 CNN、ResNet 與 Transformer，分析模型架構與資訊表示方式對預測效能的影響。

Supervised Learning Binary Classification CNN ResNet Transformer Sequential Modeling Game-State Representation
